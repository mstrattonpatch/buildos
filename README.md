# BuildOS (working name) — clickable demo

One connected construction platform: quality, programme, workforce & safety, and commercial, all sharing one project record.

**Live demo:** https://mstrattonpatch.github.io/buildos/

The whole demo is the single file `index.html`. You can also download it and double-click to open it locally, with no install needed.

## What it includes

- **Public website:** homepage, pricing, security and book-a-demo
- **Office app:** company overview, project overview, quality (defects, ITPs, hold points), programme, commercial (variations, budgets, claims), safety (SWMS), workforce, documents and site diary
- **Mobile site app:** today screen, raise a defect with photos, worker QR sign-in

## Limits of the demo

- All data is sample data, saved only in each visitor's own browser. Nobody sees anyone else's changes. Use *Reset sample data* in the profile menu to start fresh.
- The login is a role picker with no real accounts.
- The rules run in the browser. A production version needs a server, database, real authentication and file storage.
